# C Compilation Fundamentals

ALX introductory coursework covering the C compilation pipeline and simple console output.

**Stack:** C · Shell · GCC

## Contents

`0x00-hello_world/` contains preprocessing/compiler exercises and small C programs.

## Usage and scope

Compile an individual source with `gcc -Wall -Wextra 0x00-hello_world/4-puts.c -o /tmp/hello-c` and run `/tmp/hello-c`. Other exercise scripts assume a suitable C source and GCC installation.
